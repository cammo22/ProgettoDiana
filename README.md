Questo è il sito di **Progetto Diana**: una spa notturna in oro e lilla, con lo specchio-luna
che brilla al centro (Diana è la dea della luna), polvere d'oro che sale piano e perle che
galleggiano. Non è solo una vetrina: ti fa scegliere il trattamento giusto, ti fa respirare
e ti prepara il messaggio per prenotare.

## ✨ Cosa trovi nel sito

| | Sezione | Cosa fa |
|:-:|---|---|
| 🌙 | **Lo specchio-luna** | Il logo animato dentro uno specchio rotondo con la cornice d'oro che gira. È la prima cosa che vedi. |
| 🟢 | **Il tuo momento** | Sa se lo studio è **aperto adesso** (ora di Roma) e quando riapre, e ogni giorno ti lascia un **consiglio di cura** diverso. |
| 💎 | **Trattamenti** | 24 schede in 4 aree, con **ricerca istantanea** ("labbra", "rughe", "cellulite"…) e una scheda di dettaglio che ti porta dritta alla prenotazione. |
| 🪄 | **Trova il tuo rituale** | Tre domande, venti secondi: il sito ti propone i tre trattamenti più vicini a quello che cerchi. Nessun dato richiesto. |
| 🌬️ | **Respira** | Un minuto di respiro guidato: la perla si gonfia e si sgonfia col ritmo che scegli (Calma, Quadrato, Sonno). La cura di sé comincia qui, ed è gratis. |
| 🧭 | **Il metodo** | Consulenza → Diagnosi → Trattamento → Follow-up, con la linea d'oro che si disegna mentre scorri. |
| 📅 | **Prenota** | Il modulo prepara il messaggio e lo manda **su WhatsApp o per email** con un tocco. Se vuoi, anche via Formspree. |

## 📱 Dal telefono

<img src="img/readme/sito-mobile.webp" alt="Il sito visto dal telefono" width="240" align="right">

Pensato prima di tutto per il telefono:

- menu a tendina nella capsula in alto, categorie che scorrono col dito
- bottoni grandi, recensioni a carosello, modulo a una colonna
- nessuno scroll orizzontale, verificato a 390 px
- chi ha attivato **"riduci movimento"** nel telefono vede tutto fermo e tranquillo

Piccola sorpresa: dal computer, scrivi **`luna`** in un punto qualsiasi della pagina.

## Com'è fatto il sito

HTML, CSS e JavaScript scritti a mano: niente framework, niente build, niente CDN.

```
index.html            la pagina
404.html              la pagina "in relax"
css/style.css         lo stile: vetro scuro, oro e lilla, bottoni perla
css/font.css          i font, ospitati in fonts/
css/icone.css         le icone usate (generato da strumenti/icone.py)
js/dati.js            ← contatti, orari, social e tutti i trattamenti
js/app.js             stato dello studio, quiz, respiro, ricerca, schede, modulo, effetti
immagini/web/         le foto ottimizzate usate dal sito (WebP)
immagini/*.png        gli originali, per ogni futura modifica
img/                  logo scontornato, emblema, favicon, immagini del README
strumenti/icone.py    rigenera le icone quando ne aggiungi una
```

**Cambiare contatti, orari o trattamenti:** tutto in [`js/dati.js`](js/dati.js). Menu, schede,
ricerca, quiz, stato "aperto ora" e modulo si aggiornano da soli.
La guida completa, passo per passo, è in [`SITE_DOCS.md`](SITE_DOCS.md).

**Provarlo in locale**

```bash
git clone https://github.com/cammo22/ProgettoDiana.git
cd ProgettoDiana
python3 -m http.server 8000   # poi apri http://localhost:8000
```

**Pubblicazione:** GitHub Pages pubblica il ramo `main` dalla radice del repository.
Ogni push su `main` aggiorna il sito in un paio di minuti.
